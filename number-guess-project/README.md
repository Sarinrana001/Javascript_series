# Number Guess Project

A simple number guessing game made with HTML, CSS, and JavaScript.

## How to Play

- Enter a number from 1 to 100.
- Click **Check My Guess**.
- The game tells you whether your guess is too high or too low.
- You have 10 attempts to find the correct number.

## Technologies Used

- HTML
- CSS
- JavaScript

## Project Files

- `index.html` — page structure
- `style.css` — game design and layout
- `script.js` — game logic
